# Agent Instructions

## Git Workflow
- Always commit and push changes to `https://github.com/meetduggar23/SportSphere.git` after making modifications.
- Never commit `opencode.json` or `.env*` files.
- Commit message should be concise and descriptive of the changes.
- Use `git add -A` to stage all changes, then commit and push.

## Tech Stack
- Next.js with TypeScript
- Tailwind CSS
